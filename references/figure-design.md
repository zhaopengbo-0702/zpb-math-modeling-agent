# 科研图件的设计与验收

每张图先确定一个要让读者看清的结论，再选择图型、面板和最终版心尺寸。以论文中首次讨论该结论的位置安排图件。正文保留关键结果、代表性对照和必要的诊断，同口径的全量重复结果放入附录。

## 从论点选择图型

| 需要读者判断的内容 | 优先图型 | 应保留的证据 |
| --- | --- | --- |
| 状态在时间与空间上的演化 | 等值场、热力图或真实曲面 | 物理坐标、单位、色条、计算网格或样本来源 |
| 某处何时先达标、全部何时达标 | 状态场与阈值等值线、首次穿越点 | 阈值、事件定义、终点状态。用实际求解事件确定时刻 |
| 几何收缩或自由边界 | 物理坐标下的场图、移动表面线 | 当前域与留白的域外区域 |
| 网格或时间积分是否收敛 | 误差随步长的双对数图、停止时间收敛曲线 | 实际重算点、统一的误差范数与同一物理问题 |
| 参数估计和观测一致性 | 观测点、拟合曲线与区间 | 区分数据点和曲线，注明区间来源与水平 |
| 两个参数的相关性 | 后验样本等密度线或二维密度 | 真实采样、参数约束、足够有效样本 |
| 多个参数的影响大小 | 变化区间、弹性或 Sobol 指标 | 具体扰动范围、同条件的完整重算、指标定义 |
| 预测或低维代理是否可靠 | 观测与预测轨迹、预测对照或残差诊断图 | 独立验证集、对齐采样区间、相同轴尺度或理想预测线 |
| 组间分布和同一样本的差异 | 有足够样本时用箱线图或小提琴图，少量样本用散点，配对用连线 | 样本点或数量、配对单位、分位数或密度的含义 |
| 误差如何随时段、条件或变量变化 | 分面轨迹、误差热力图或剖面图 | 比较条件、统计量、时间或空间坐标、共同标度 |
| 降阶截断与重构质量 | 奇异值谱、误差随维数曲线 | 加权内积、留出误差、状态与非线性项的区别 |

互补视图能共同回答一个问题时，可组织为有面板编号的组合图。共享可比的轴、量纲和图例，检查每个面板在最终尺寸下可读。每幅主图独立编号和导出。二维视图能清楚呈现主要证据时，优先留在正文。三维曲面用于展示有实际坐标的场、参数响应或边界。

## 颜色、字体与输出

- 同一变量、方法、状态和分组在可比图中沿用相同的颜色与符号。可直接比较的面板和附录系列使用相同的坐标范围、色阶与归一化。不同任务可用各自合适的配色。修订时先记录用户已确认的图件与样式，保留认可的图及其配色，用作其他同类图的参考。
- 默认白底、细轴线和有限的主刻度，按数据语义选择区分类别的离散色板、表达大小的顺序色阶或围绕明确参考值的发散色阶。正文中反复对照的类别可增加线型或点形编码。图标用于表达对象或操作，背景与强调色服务于版面层级。
- 标签、图例和注释随论文语言。数学记号、单位和字体服从用户要求与模板。英文指定 Times New Roman 时检查实际字形，要求 LaTeX 风格时保持公式、变量和上下标与正文一致。中文可使用已安装的黑体或思源黑体。导出后核对字形、负号与字体替代。
- 重要趋势图、对照图、多面板图和流程图优先接近正文版心全宽。按嵌入后的尺寸设置轴名、刻度、单位、图例和标注字号。半宽图或双栏单栏图以这几个要素都清楚可读为前提。若缩排后读不清，先裁掉外围空白、加宽图件，再缩短标签或重排面板。必要时将拥挤的面板拆成两张图。定量主图默认导出独立矢量 PDF、SVG 和 600 dpi PNG，并以实际交付契约为准。二维线条和文字保留矢量，密集三维曲面可单独栅格化。
- 可用 `scripts/zpb_plot.py` 设置字体、单图画布、正值对数色阶和多种输出格式。定量图采用可复现且能通过验收的工具。用户指定 Origin 等软件时，先用嵌入尺寸的样张检查字体和矢量输出。已安装的 SciPilot 制图技能可辅助数据图选型与验收。参考图需要分层 PSD 时可选用 Photoshop 重构技能。指定 PPTX 的图按原生 PowerPoint 路线处理。

## 可编辑的流程图与示意图

1. 总览图按问题或阶段组织。先列清输入、主要计算步骤、输出及跨阶段依赖，再用方框和有方向的箭头表达对应关系。每个编号与正文问题或具体步骤对应。测量、处理、反馈或数据传递等不同含义通过标签或图例区分。把相关输出集中到一个容器里，并检查箭头对应实际起点和终点。
2. 短标签与易识别的图标配合，详细推导和说明留给正文。总览图默认用短标签、结构和功能图标交代流程，删去与图注重复的页脚小字。用户指定纯文字时按其要求处理。方法图仅在表达关键变换或约束时保留必要公式，并采用与正文一致的 LaTeX 记号。按用户认可的样图检查字体层级、对齐、间距与图标风格，保留具体拓扑和科学含义。
3. 用户要求 PowerPoint 时交付可打开编辑的 `.pptx`。分组容器、框、图标、文字与连线使用原生可编辑对象，逻辑连接线尽量锚定到对应形状。公式需要独立修改时采用可编辑公式，或将公式保留为可单独替换的矢量对象并附 LaTeX 源。论文插图从同一版本源稿导出矢量 PDF。
4. 逐类决定需要制作的 PPT 图。全篇总览标明每个分问与验证流程。分问流程突出关键分支、输入和输出。模型框架突出数据流、耦合或反馈。装置与测量示意图标出器件、信号路径和采集端点。框内把输出名称与单位、说明或采样信息归在一起，连线结束在相应框边。已有科研数据图通过生成脚本维护。
5. 在 PowerPoint 或兼容编辑器中确认主要对象可分别选中，移动节点后检查连接线。打开导出版核对箭头方向、端点、交叉与遮挡，检查文字不会被连线穿过、倾斜、裁切或因换行产生重叠。交付前在论文中再看一次实际显示效果。

## 空间场与三维曲面的细节

色条范围由完整物理数据确定。同一比较组使用相同标度。正值数据跨多个量级时可用对数归一化，清楚标注并以原单位显示刻度。含零值或负值时先选相容的色阶或定义掩膜。由真实场的等值线绘制阈值边界。

参考域求解结果应映射回实际坐标再绘制收缩图。当前表面外留白。选用能保留局部极值与达标边界的视角、长宽高比例和截面线。需要精确读数时补充同尺度俯视图。

后验可信带、参数预测区间和测量误差带表达不同对象，图注须说明其来源。数值收敛图使用实际重算结果，并区分采样点与拟合趋势。

## 验收

1. 核对数据、变量、量纲、样本范围、区间、图注和正文数字，使其追溯到求解或统计结果。检查正负、对数、色阶与阈值位置。
2. 单独渲染每张图。打开编译后的 PDF，以实际显示尺寸逐图检查轴名、刻度、单位、图例、色条、上下标和箭头。多面板图逐个检查最小字号。发现读不清的元素时回到图源或版面调整，再编译复查。检查关键点是否被标记或图例遮挡，比较图的同类标签是否一致。
3. 重新渲染论文，先用页面缩略图检查空白与图文分布，再放大检查图注、正文引用、浮动位置和表图之间的段落。用户指定与某段同页时，检查文字和图在最终 PDF 的实际位置。逐项落实批注后，对同类型图和页面应用相同检查。页面预算、摘要和目录按论文排版规则处理。 [论文写作与排版](paper-writing.md)
4. 缺乏独立信息的图可删减。图文覆盖目标优先用实际结果、诊断和解释完成。修订后重新导出受影响的源图、论文插图与最终 PDF。
