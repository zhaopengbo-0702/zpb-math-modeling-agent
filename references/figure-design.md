# 中文科研图件的设计与验收

当开始制作或重做论文图件时读取本文件。图件回答一个具体的科学问题；图型和复杂度由数据决定。

## 从论点选择图型

| 需要读者判断的内容 | 优先图型 | 应保留的证据 |
| --- | --- | --- |
| 状态在时间与空间上的演化 | 连续色阶的等值场；必要时真实曲面 | 物理坐标、单位、颜色条、实际计算网格或样本来源 |
| 某处何时先达标、全部何时达标 | 状态场与阈值等值线、首次穿越点 | 阈值、事件定义、终点状态；不能以最后一个输出采样时刻代替求解事件 |
| 几何收缩或自由边界 | 物理坐标下的场图、移动表面线 | 当前域与域外空白；域外不能补零伪装为低浓度 |
| 网格或时间积分是否收敛 | 误差随步长的双对数图、停止时间收敛曲线 | 实际重算点、统一的误差范数与同一物理问题 |
| 参数估计和观测一致性 | 观测点、拟合曲线与区间 | 数据点和曲线区别、区间来源与置信水平 |
| 两个参数的相关性 | 后验样本等密度线或二维密度 | 真实采样、参数约束、足够有效样本 |
| 多个参数的影响大小 | 变化区间、弹性或 Sobol 指标 | 具体扰动范围、同条件的完整重算、指标定义 |
| 低维代理是否可靠 | 预测对照与误差颜色编码 | 独立验证集、相同轴尺度、理想预测线 |
| 降阶截断与重构质量 | 奇异值谱、误差随维数曲线 | 加权内积、留出误差、状态与非线性项的区别 |

没有时空场就不生成装饰曲面。二维图已经清楚表达结论时，不为视觉复杂度增加三维轴。若曲面遮挡阈值或读数，以等值场为正文主图，三维图作补充。

## 默认外观

- 全中文坐标、图例和说明；数学符号按全文统一定义，单位与原始数据一致。
- 每次运行只绘制一张主图，色条可以是附加轴。各图独立编号和导出，不拼接多个面板，不把截图当作图件。
- 使用白底、完整细黑框、有限的主刻度。蓝色、朱红、青绿色用于类别区别；连续标量优先 `viridis` 或 `cividis`，有正负偏差才使用以零为中心的发散色阶。
- 图片按最终排版尺寸制作，通常宽约 6 英寸；正文缩放后坐标与图例仍可读。使用固定字号，不能用超大标题挤占数据区。
- 默认 `plt.rcParams['font.sans-serif'] = ['SimHei']` 与 `plt.rcParams['axes.unicode_minus'] = False`。跨平台没有黑体时检测并使用 Noto Sans CJK SC 等已有中文字体；无可用字体时明确报告，不静默导出方框字符。
- 每张图导出 PDF、SVG 和 600 dpi PNG。二维曲线与文字保留矢量；密集三维曲面可以高分辨率栅格化。SVG 编辑需要接收方具备相应字体，不随技能分发系统字体。
- 不用发光、阴影、纹理或渐变背景表达并不存在的机制。颜色变化必须对应数据或清楚定义的分组。

`scripts/zpb_plot.py` 提供已独立编写的字体、单图画布、正值对数色阶和三格式导出工具。它不要求安装 boviz 或 acadplot；有这些库时可按其许可选用，但仍需保持本文图件规范。

## 空间场与三维曲面的细节

色条范围以完整物理数据决定，同一比较组使用相同标度。浓度跨多个量级时可用对数归一化，必须清楚标注并以原单位显示刻度；零值与负值不能直接进入对数色阶。阈值曲线由真实场的等值线产生，而不是手画一条装饰线。

参考域求解结果应映射回实际坐标再绘制收缩图；当前表面外留白。适量截面线可以显示演化，但不能遮盖局部极值。曲面使用合理视角、固定长宽高比例和完整标签；三维投影不能隐藏达标边界。曲面与俯视图若都必要，分别导出两张独立图。

后验可信带、参数预测区间和测量误差带表达不同对象，图注必须说明其来源。数值收敛图要有真实重算结果，不能把光滑拟合线写成网格验证。

## 每张图都需验收

1. 核对数据文件、变量、量纲、单位换算及图注中的数字，能追溯到统一结果数组。
2. 单独打开最终 PNG，按论文中的实际显示尺寸检查中文、负号、上下标、颜色条、图例和注释。
3. 检查标签无截断、无重叠；图例不遮挡关键极值；阈值点与求解事件一致。
4. 检查正负或对数刻度是否符合数据范围，离散色阶有无伪造连续性的暗示。
5. 将图放进论文重新渲染，检查浮动体、图注、正文交叉引用及页面比例。

图没有比文字、表格或已有图增加清晰的信息时，删掉该图。美观以可读、精确和证据完整为基础。
