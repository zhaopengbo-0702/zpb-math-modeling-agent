# 中文建模论文与单页摘要

## 从结果写正文

每问形成完整论证链：题目要求 -> 状态/变量 -> 控制方程或优化目标 -> 初边值/约束 -> 离散或估计方法 -> 实际求解配置 -> 结果 -> 可由结果支持的机制解释。先完成计算和核对，再补齐摘要与结论。

公式密度由数学工作决定。定义符号、单位、空间与算子；给出弱形式、变换、离散、梯度、正则化、概率模型、误差估计等确实使用的数学对象。公式之后解释它如何进入求解或支持结论。避免连续堆放与主线无关的公式。

正文以“建立……”“采用……求解”“计算得到……”“对照表明……”等具体动作组织。去掉“本模型非常先进”“评委可能质疑”“尽管采用高阶工具但不能声称……”一类修辞。必要的适用条件写在模型假设和方程旁，误差来源体现在对照、区间名称和图注中。

## 默认七章

1. 简介：背景和题目重述；不单设文献综述。
2. 问题分析：共同输入与各问计算思路。
3. 模型假设：每条有用途，假设进入相应方程。
4. 名词解释及主要符号说明：物理/统计含义、统一单位。
5. 模型建立与求解：按题目逐问完成推导、计算与结果。
6. 灵敏度分析与鲁棒性检验：真实重算、同条件比较和结论。
7. 模型的评价、改进与推广：优点、具体误差来源、可操作改进与适用推广。

题目、赛事规范或用户提供的优秀论文结构有明确要求时，以其为准。参考文献随正文就近引用，按首次出现顺序编号。

## 摘要的内容分配

摘要包含总述、各问、总结和关键词。总述用一段交代问题对象、主要困难和统一模型。每问用一段说明“针对什么问题，建立什么模型，采用什么求解方法，得到哪些关键数值，说明什么”。最后两三句归纳共同规律及用途。数值从 `numeric_facts.json` 与结果数组交叉核对，保留合理精度和必要配置。

重要模型、关键结果和结论用 `\textbf{}`，不使用红色。题目若要求多个阶段，每段结论应回答相应阶段，不能只罗列方法名和数字。

## 第一页充实且不溢出

1. 使用用户模板原有标题、摘要、段距、字体与版心。
2. 初稿编译，查看摘要和关键词所在页。提取文字只能辅助判断，最终需看渲染页面。
3. 空白较多时优先补充逐问数值、同条件对照、误差验证和具体结论；这些内容必须已有计算来源。
4. 溢出时删去重复背景、重复方法说明或次要参数；保留各问的核心数值和结论。不要用夸张内容填充。
5. 目标为第一页版心充实并保留自然底部空间，关键词留在第一页。有目录时第二页从目录开始。自然语言调整最多三轮后重新评估信息密度，不通过缩小到难读字号来强塞。

## 数值、引用与命名

结果表采用题设四舍五入，内部计算保留原精度。不同网格、样本量和参数设置有独立名称；相同物性对照才能量化几何效应。后验可信区间、设计输入的预测分位数、数值误差带各自准确命名。

文献只支撑其实际讨论的机制或方法。本文推导、本文数值及他文结论明确区分。正式年份取已核验的卷期或出版日期，不能把DOI中的年份当出版年份。

## 修订与源文件

已有最终稿时先阅读活动 `main.tex` 的递归输入。修改模块化源并重新生成所需单文件；如果用户直接编辑单文件，则先保存差异并合并。不要运行从旧快照重建整稿的历史程序。

单独生成表格和数字宏，单独绘制最终图件。生成器必须声明输出文件，避免一个旧脚本同时重建正文、旧配色图和过期摘要。每次交付核对PDF、源文件、Excel及压缩包属于同一版本。
