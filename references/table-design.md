# 表格设计与结果叙述

图件揭示空间结构、动态演化和参数响应，表格提供可核对的精确数值。先从题目要求和实际计算输出建立“表格清单”，再排版，不用大量重复表格填充篇幅。用户提供的模板和已确认终稿的表格样式优先，保留其列次序、单位、采样时刻、保留位数和紧凑程度。

## 按研究任务安排表格

适用时至少考虑以下信息预算：

- 一张主要符号与单位表，涵盖正文反复使用的状态、参数及指标；不将每个局部辅助变量全部塞入。
- 每个问题至少一张核心结果表，直接回答该问要求的数值、方案或判断。题目分别规定温度、含水率等多张表时按其要求分别给出。
- 一张主要模型参数及数值配置表，列出物性、算法、网格、容差、随机种子、样本数等与复现有关的配置。来源或设定依据可另列一栏。
- 一张收敛或独立验证表，比较相同条件下的网格、时间控制、留出样本或基准解。没有真实重算时先完成计算，不能用“合理”数字补表。
- 一张敏感性结果表及一张鲁棒性对照表，分别呈现参数扰动和处理选择的重算结果。该类问题不适用时说明方法选择，不造数据满足数量。

这是信息覆盖预算，不是所有题目必须照搬的固定张数。优化、统计、图论、预测等任务可改为方案对比、估计值与区间、消融、误差或场景稳定性表。原始秒级场数据和全部蒙特卡洛样本保存在附件，正文保留读者决策需要的摘要。

## 精确、可读且与图互补

每张表要有明确问题和一句以上的正文解释：先交代比较对象与条件，再指出最重要的数值差异，最后给出对本问的结论。解释真实量级和趋势，不逐格复述。表中出现的关键数值与正文、摘要、图注应来自同一计算结果和数值事实台账。

采用白底黑字、三线表、表题在上。单位写入列标题，数值按列统一精度并合理右对齐；必要时调整量纲，例如以小时、毫米、百分比或规定的幂次比例报告，避免微小非零值被显示成 0.0000。区间同时写清置信度、可信度或条件分位数的含义。缺失或物理域外值使用空白或约定符号，并在正文说明，不能补零冒充观测。

默认复刻终稿的自然宽度三线表：`\centering\small`、`tabular`、普通字重表头，数值列右对齐、文本列左对齐。不将表格强行拉满 `\linewidth`，不重设模板的行距、表题样式或 `\arraystretch`。宽表先按物理量、问题或比较维度拆成独立表，必要时为个别长文本列明确选择宽度；超过八列时拆表或将完整长表移到附录。长列名可换行，不使用极小字号、整表缩放或截图表格，表题不要堆公式。相同结果可同时有图和表，但图应展示形状或关系，表应提供精确取值、指标或参数，二者各有用途。

## 使用统一导出工具

`scripts/export_tables.py` 从一份 JSON 数据同时生成独立 LaTeX 三线表和 Excel 工作簿，避免人工抄写造成不一致。将这份源数据保存到 `PROJECT/data/table-spec.json`，使它与计算数据一起收入复现包。格式如下：

```json
{
  "tables": [
    {
      "id": "validation",
      "caption": "空间加密检验",
      "label": "tab:validation",
      "sheet": "空间加密检验",
      "header_note": "相同物性及停止准则下的独立重算",
      "columns": [
        {"key": "mesh", "label": "径向区间数", "decimals": 0},
        {"key": "time", "label": "停止时间", "unit": "h", "decimals": 4}
      ],
      "rows": [
        {"mesh": 40, "time": 50.83},
        {"mesh": 80, "time": 50.82}
      ]
    }
  ]
}
```

上述数字仅说明输入结构，实际论文必须替换为本次真实计算结果。

```console
python scripts/export_tables.py PROJECT/data/table-spec.json --output PROJECT/tables
```

主文档加载 `booktabs`，使用显式段落列宽时另加载 `array`，再使用 `\input{tables/validation.tex}`。每个表独立保存为 `id.tex`，工作簿 `tables.xlsx` 每表一页。`table-manifest.json` 记录源数据哈希、表标识、表头说明、显式列宽、数据来源位置与输出文件哈希。源 spec、活动表格片段、工作簿和 manifest 随复现包交付；只有题目明确要求并写入 `required_deliverables` 的文件才进入核心提交包。正文引用工具生成的安全 `label`，不手写表编号。

可选的表级 `header_note` 在 `\toprule` 后作为跨全表的普通文字说明，例如“径向距离 / cm；表面列对应当前半径”，随后才是各列标题。Excel 将其写入合并表题单元格 A1 的第二行，列标题仍在第 2 行，数据从第 3 行开始。可选的列级 `width_cm` 必须为正的有限数值，例如 `{"key": "meaning", "label": "含义", "width_cm": 6.8}`；只有明确给定时才生成可换行的 `p{6.8cm}` 列，不自动推断列宽。选择宽度后仍需编译核对版心和换行，不用不合理的小列宽凑版。未设置宽度的多行文本使用自然宽度的 `\shortstack` 保留换行。

ID 使用小写英文、数字和连字符。列的 `decimals` 默认为 4，仅控制显示；Excel 存储源数值，不先四舍五入。Excel 本身的数值精度有限，长编号应使用字符串。`null` 在 LaTeX 表中显示为 `---`，在 Excel 中为空。所有字符串按文本保存，`=...` 等字符串不会被写成公式；LaTeX 特殊字符会转义，不把外部字符串作为可执行 LaTeX。

工具先验证全部表格，再写输出。缺列、重复 ID、重复工作表名、NaN/Inf、非法工作表名或超过八列均会报错。输出目录已有文件时默认停止；确认是本次输出后可加 `--overwrite`，只替换当前生成文件，保留其他文件。最后编译检查长表、单位、字形、表题和分页，并核查是否需要题设指定的额外完整结果工作簿；摘要表工作簿不能自动替代题目要求的完整数据附件。
